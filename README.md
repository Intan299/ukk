# TANTICA KASIR

# Deskripsi Aplikasi
TANTICA KASIR adalah aplikasi kasir sederhana yang digunakan untuk mengelola data barang, customer, stok, dan transaksi penjualan.

# Tujuan
Membantu mempermudah pengelolaan barang dan pencatatan transaksi penjualan.

# Fitur Aplikasi
1. Login dan Register
2. Data Barang (Tambah, Tampil, Update, Delete)
3. Data Customer (Tambah, Tampil, Update, Delete)
4. Stok Barang
5. Transaksi
6. Laporan Transaksi
7. Logout

# Database
Nama database: `kasir`

# Tabel database:
- admin
- barang
- customer
- detail
- login
